# Balaji — AI/ML & Data Science Portfolio

A responsive animated portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract this folder.
2. Open `index.html` in your browser, or use VS Code + Live Server.
3. Replace all profile and social placeholders before publishing.

## Personalize before publishing
- Replace `assets/profile-placeholder.svg` with your professional photo (rename it `profile.jpg` and update the `src` in `index.html`, or keep the SVG until ready).
- Add your résumé PDF at `assets/resume.pdf`.
- Replace `YOUR-GITHUB-USERNAME`, `YOUR-LINKEDIN-USERNAME`, and `YOUR-EMAIL@example.com`.
- Update the project cards with accurate descriptions, technologies, repository links, live demos, and completion status.
- Verify your education details and skill list.

## Deploy free with GitHub Pages
1. Create a GitHub repository and upload the contents of this folder.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the published URL shown on the Pages screen.

## Notes
- The résumé download button points to `assets/resume.pdf`; add your real PDF.
- The contact button opens the visitor's email app once you replace the email placeholder.
- Project cards are editable examples/placeholders, not claims that every project is complete.
- Animations respect the user's reduced-motion setting.
